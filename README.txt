FOR YANNY — WEBSITE CODE

Open index.html in any modern browser. No installation or server is needed.

To personalize it further, open index.html in a text editor and search for:
- "Dear Yanny" to change the letter
- "Open me, Yanny" to change the four reveal cards
- "const dateIdeas" to change the date picker choices
- "Juliana Ablen" or "Mami" to adjust names
- "const nicknameNotes" to change each nickname's message
- "const heartNotes" to change the messages from the big heart
- "Our little scrapbook" to change the book title and captions
- the photos/ folder to replace any picture (keep the same file names)

The site includes an opening letter, reveal cards, a random date idea picker,
virtual hugs, floating hearts, nickname notes, a tappable heart, and a
confetti surprise. It works on phones and desktop.
The scrapbook opens like a book. Turn six spreads, tap photos for a larger
view, and add heart, star, or flower stickers to the pages.
The page also includes a nine-second animated video made from three couple
photos and a button that showers the page in hearts. Keep the videos/ folder
beside index.html when uploading the site.

The decorative Google Fonts load when online. The page uses system fonts
when offline.
